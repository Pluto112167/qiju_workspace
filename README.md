# 栖居 · 个人工作台

一个低饱和、本地优先的个人工作台。没有账号、没有服务器，打开网页就能用；所有内容自动保存在当前浏览器里。

## 直接打开

1. 找到 `index.html`。
2. 双击，用 Edge、Chrome 或 Safari 打开。
3. 第一次打开后，建议先去「设置」给督导起个名字，并确认喝水、洗澡、单词提醒时间。

不需要安装、不需要启动服务，也没有外部依赖。

## 手机访问

推荐部署到 GitHub Pages：

1. 在 GitHub 新建一个仓库。
2. 上传 `index.html`、`styles.css`、`app.js`、`avatar.png`、`avatar-full.jpg`、`manifest.webmanifest`、`icon-192.png`、`icon-512.png`、`apple-touch-icon.png`。
3. 打开仓库的 **Settings → Pages**。
4. Source 选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
5. 等一两分钟，打开 GitHub 给出的网址。
6. 在手机浏览器里选择「添加到主屏幕」。

GitHub Pages 只托管网页代码，不会看到你的任务和记录。手机和电脑的数据默认各自独立；需要迁移时，用「设置 → 数据与备份」导出 JSON，再到另一台设备导入。

## 第一版包含

- 首页仪表盘：本周待办、进行中、本周逾期、本周完成率、今日待办、习惯打卡、项目进度、本周学习时长、睡眠热力图
- 任务：快速添加、截止日期、计划日期、时间块、项目、分区、标签、优先级、完成/进行中状态
- 月历：按日期查看任务，点击某天可以查看或添加
- 周视图：7 天时间轴，点击空白时间格可按半小时添加任务
- 每日记录：心情、喝水、至少两餐、运动、洗澡、单词、学习时长、睡眠
- 学习：手动记录学习时长；雅思/学习项目按分区和任务计算进度
- 项目：目标、分区、标签、颜色、目标日期、手动进度覆盖；可以按标签筛选项目，打开项目能看到里面的全部任务
- 统计：近 8 周完成率、近 8 周学习、近 30 天习惯、睡眠概览、累计逾期和总完成率
- 提醒：喝水（默认 9:00–21:00 每 2 小时）、三餐（08:00 / 12:00 / 18:30）、洗澡 21:00、单词 20:30；时间都可改
- 督导角色：原创虚拟形象，名字、称呼、性格、监督强度、自定义开场白都可以自己设置
- 数据：本地自动保存、备份到指定位置（可存 D 盘）、JSON 下载/导入、清空数据

## 关于数据

- **自动保存**：每次修改后自动写入当前浏览器的本地存储。它位于浏览器配置目录（通常在 C 盘），但都是很小的文本，通常只有几 MB，不会把 C 盘撑满。
- **备份到指定位置**：在「设置 → 数据与备份」点击「备份到指定位置」，可以直接选择 `D:\栖居备份\qiju-backup.json` 之类的路径。浏览器安全策略不允许网页后台静默写 D 盘，所以这一步需要你每次确认保存位置。如果浏览器不支持，会自动退回下载方式。
- **下载 JSON**：如果浏览器不支持选择保存位置，就用「下载 JSON」，再手动移动到 D 盘或网盘。
- **建议频率**：每周一次，或者每次大量整理任务/项目之后备份一次。换浏览器、清理浏览器数据前也先备份。
- **注意**：清理浏览器缓存、更换浏览器或使用隐私模式，都可能导致本地数据丢失。个别浏览器会限制直接双击打开的 `file://` 页面使用本地存储；如果发现刷新后数据没有保留，请改用 GitHub Pages 或本地服务器访问。
- **提醒**：只在页面打开时工作，浏览器关闭后不会弹出系统通知。
- **不做的事**：第一版没有计时器、没有内容库、没有复杂课表导入、没有云同步。课表你手机上已有，周视图只显示任务。

## 自定义督导

进入「设置 → 督导角色」：

- 名字留空时显示为「督导」
- 「怎么称呼你」会出现在首页问候里
- 说话风格会影响自动文案的语气
- 自定义开场白一旦填写，就会固定显示，不再根据状态自动变化
- 可以把督导完全关闭，只保留工作台
- 首页头像或设置里的「查看形象」可以打开大图

督导的虚拟形象使用你提供的“书房里的白发绅士”图片，并裁成适合圆形头像的版本。角色文案全部内置在本地，不调用 AI，也不会上传任何内容。首页和提醒中的话会根据时间、逾期任务、喝水、学习记录、说话风格和监督强度切换；不是实时生成式 AI。

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | 页面入口 |
| `styles.css` | 视觉与响应式布局 |
| `app.js` | 数据、交互、日历、周视图、统计、提醒 |
| `avatar.png` | 圆形头像用的裁切版 |
| `avatar-full.jpg` | 查看形象用的大图 |
| `manifest.webmanifest` | 手机添加到主屏幕的配置 |
| `icon-192.png` / `icon-512.png` | 应用图标 |
| `apple-touch-icon.png` | iOS 主屏幕图标 |
